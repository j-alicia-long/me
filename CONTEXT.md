# Ubiquitous Language — jennifer's personal website

Glossary of domain terms for this site. Keep implementation details out.

## Terms

### Project

A hand-curated personal software project showcased on the Projects page.
Curated means Jennifer decides the list explicitly — projects are not
auto-discovered from GitHub. Professional (Duolingo) work and creative
non-code work are *not* Projects; the latter lives under Photography (and
eventually Bookshelf).

### Live link

An optional URL where a visitor can try a Project — a deployed website, a
web-store listing, or similar. Not every Project has one (some run locally
or have no public deployment). Distinct from the Repo link.

### Repo link

The URL of a Project's public GitHub repository. Every Project has one.

### Preview image

The single representative image shown on a Project's card. A Project may
temporarily lack a preview image, in which case a placeholder is shown
until Jennifer supplies a screenshot.

### Card

The unit of display on the Projects page: preview image with the Project
name and icon links (Repo link always; Live link when present) beneath it.
Clicking the preview image opens the Live link when present, otherwise the
Repo link. Cards intentionally carry no descriptions or tags — the image
does the talking.

### Photo

An entry in the Photography gallery, with date, location, caption, and
tags. Unrelated to Projects.

### Tag

A category label used to filter Photos on the Photography page. Projects
do not use tags.
